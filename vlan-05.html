SAS vs. SATA vs. NVMe, PCIe lanes and generations, ECC/RDIMM/LRDIMM/NUMA memory, and Rack/Blade chassis.

PCIe Expansion Bus & Riser Architecture

  • Point-to-Point Serial Lanes: Unlike legacy shared-bus PCI, each PCIe slot gets dedicated bidirectional serial lanes (x1, x4, x8, x16) wired directly to the CPU or PCH chipset.
  • Physical vs. Electrical Lanes: A slot can be physically x16 long while wired electrically as x8 (written as x16 @ x8); always check electrical lane count for high-bandwidth NICs/HBAs.
  • Generation Throughput (per lane): PCIe 3.0 = ~1 GB/s per lane; PCIe 4.0 = ~2 GB/s per lane; PCIe 5.0 = ~4 GB/s per lane (doubles every generation).
  • PCIe Riser Cards: Right-angle adapter boards used in low-profile 1U/2U rack servers so full-height expansion cards mount horizontally parallel to the motherboard.

Server Memory (ECC, RDIMM, LRDIMM) & NUMA

  • ECC (Error-Correcting Code) RAM: Uses extra parity bits (72-bit bus vs. 64-bit non-ECC) to detect and automatically correct single-bit memory errors on the fly and halt on uncorrectable multi-bit errors.
  • UDIMM vs. RDIMM vs. LRDIMM: Unbuffered (UDIMM) has no register; Registered (RDIMM) adds a register buffer between CPU and DRAM for stability at high capacities; Load-Reduced (LRDIMM) buffers both address and data lines for maximum RAM density. Never mix DIMM types in the same server.
  • NUMA (Non-Uniform Memory Access): In multi-socket servers, each CPU socket has direct local memory banks; accessing RAM attached to Socket 2 from Socket 1 crosses the interconnect bus (UPI/Infinity Fabric) with higher latency.
  • Memory Mirroring & Sparing: BIOS hardware redundancy modes that mirror RAM channels or reserve spare ranks to survive full DIMM failure.

Server Chassis Form Factors & Internal Cooling Hardware

Rackmount (1U, 2U, 4U)

  • Standardized 19-inch width; height measured in Rack Units (1U = 1.75 inches / 44.45 mm).
  • 1U uses small high-RPM fans (loud); 2U/4U allow larger, quieter fans and more PCIe slots/drive bays.

Blade Servers & Chassis

  • Ultra-dense modular compute blades (CPU + RAM + local boot) slotting into a shared Blade Chassis.
  • Chassis provides shared power supplies, cooling fans, backplane networking, and management modules.

Airflow Shrouds & Hot-Swap Fans

  • Air Baffles / Shrouds: Plastic ducts directing front-to-rear cold air directly over CPU heatsinks and DIMMs.
  • N+1 Hot-Swap Fan Modules: Tool-less fan cartridges replaceable while running; failure of 1 fan triggers remaining fans to spin up to 100% RPM.
