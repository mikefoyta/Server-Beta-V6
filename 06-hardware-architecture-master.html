Single-CPU in a Dual-Socket Chassis Rule: Modern CPUs house both the memory controller and PCIe root complex on-die. If CPU Socket 2 is empty, every DIMM slot and PCIe riser wired to Socket 2 is completely dead!

2. Memory Channel Interleaving, 2DPC & Protection Modes RAM Architecture

  • Primary-Slot-First Interleaving Rule: A single-socket CPU with 16 DIMM slots is arranged as 8 channels × 2 slots per channel (2DPC). If you have 8 DIMMs, install 1 DIMM in the primary (color-coded) slot of ALL 8 channels—never pack 2 DIMMs into 4 channels and leave 4 channels empty (which cuts bandwidth in half).
  • 2DPC Clock Step-Down: Populating 2 DIMMs per channel increases electrical capacitance, causing the memory controller to automatically step down MT/s speed (e.g., 4800 → 4400 MT/s) to preserve signal integrity. Normal physics—not a fault!
  • Strict No-Mixing Rule: Never mix UDIMM, RDIMM, and LRDIMM—or ECC and non-ECC—in the same server.
  • ECC vs. Mirroring vs. Sparing:
    • Single-Bit ECC: Corrected automatically on the fly; recurring errors on one stick → run vendor memory diagnostics.
    • Multi-Bit ECC: Uncorrectable fatal crash/reboot → replace the defective DIMM immediately.
    • Memory Mirroring: 50% usable RAM (real-time hardware RAID 1 for RAM).
    • Rank Sparing: Reserves 1 rank per channel as a hot spare to copy failing ranks before they crash.

4. Rack Weight Hierarchy & Out-of-Band Management (BMC) Physical & OOB

  • 42U Rack Weight Distribution: Heavy UPS batteries & SAN disk shelves at 1U–10U (bottom) → Compute servers in 12U–30U (middle) → Lightweight patch panels & Top-of-Rack switches at 38U–42U (top).
  • Out-of-Band BMC (iDRAC / iLO / IPMI): Independent microcontroller with its own dedicated NIC and standby power rail—lets you view frozen OS screens (KVM-over-IP), mount virtual ISOs, read System Event Logs (SEL), and hard-cycle power when the OS is dead. Must sit on an isolated OOB management VLAN with HTTPS/TLS 1.2+ only.
  • AI Interconnect Architecture: PCIe Gen 5 bottlenecks multi-GPU LLM training; NVLink / NVSwitch creates a direct high-speed GPU-to-GPU mesh, while GPUDirect Storage (GDS) moves NVMe data straight into GPU VRAM without CPU bounce buffers.
