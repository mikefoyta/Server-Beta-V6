Service / Protocol Port(s) & Transport Core Function & Server Role
DNS (Domain Name System) UDP/TCP 53
(DoH: 443 / DoT: 853)		 Resolves hostnames to IPs (A IPv4, AAAA IPv6, PTR reverse, CNAME alias, MX mail, SRV AD/service discovery); TCP 53 used for Zone Transfers (AXFR/IXFR).
DHCP UDP 67 (Server) / 68 (Client) Dynamic IP assignment via DORA (Discover, Offer, Request, Acknowledge); servers use DHCP Reservations or Static IPs; DHCP Relay (ip helper-address) forwards broadcasts across routers.
NTP (Network Time Protocol) UDP 123 Stratum-based clock synchronization across servers; mandatory for Kerberos tickets, TLS certificates, SIEM log correlation, and cluster consensus.
SNMPv3 UDP 161 (Poll) / 162 (Trap) Monitors server/switch metrics via OIDs/MIBs; SNMPv3 adds authentication and AES encryption (replaces insecure plaintext SNMPv1/v2c community strings).
Syslog UDP 514 / TCP 6514 (TLS) Centralized log forwarding from Linux servers, hypervisors, and network appliances to a central log collector/SIEM.
SSH / RDP / WinRM / LDAPS TCP 22 / 3389 / 5985-5986 / 636 Encrypted remote administration (SSH, RDP, PowerShell Remoting HTTPS 5986) and encrypted directory queries (LDAPS 636).

NIC Bonding, VLAN Tagging & MTU

  • IEEE 802.1Q VLAN Tagging: Inserts a 4-byte VLAN ID tag into Ethernet frames so a single physical trunk NIC can carry isolated traffic for Management, Production, vMotion, and Storage VLANs.
  • LACP (IEEE 802.3ad Link Aggregation): Dynamically bundles multiple physical NIC ports into one logical interface for link-level failover and multi-stream bandwidth aggregation (requires matching LACP configuration on switch ports).
  • Active/Standby NIC Teaming: Fails over traffic to a passive NIC if the primary link drops without requiring switch-side LACP configuration.
  • Jumbo Frames (MTU 9000): Increases Ethernet payload from default 1500 bytes to 9000 bytes to boost high-throughput storage/VM migration efficiency—must match on host NIC, switch ports, and target.

CLI Network Troubleshooting Toolkit

  • ping (ICMP Echo): Verifies Layer 3 reachability and round-trip latency; ping -f -l 8972 <ip> (Windows) or ping -M do -s 8972 <ip> (Linux) tests end-to-end Jumbo Frame MTU without fragmentation.
  • traceroute / tracert: Maps every Layer 3 router hop along a path to isolate where packets are dropped or delayed.
  • nslookup / dig: Queries DNS records directly to isolate DNS resolution failures from raw IP connectivity issues.
  • netstat -ano / ss -tulnp: Displays active TCP/UDP listening ports, established connections, and owning Process IDs (PIDs) on the local server.
  • tcpdump / Wireshark: Captures raw live packets on a server NIC to diagnose handshake failures, VLAN tag mismatches, or asymmetric routing.
  • iperf3: Measures actual raw TCP/UDP network throughput between two endpoints to verify 10GbE/25GbE link performance.
