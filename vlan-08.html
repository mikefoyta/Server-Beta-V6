Server Security, Hardening & Access Control

TPM 2.0, UEFI Secure Boot, HSM, SEDs, CIS/STIG hardening, SELinux, Kerberos/RADIUS/TACACS+, and physical controls.

DOMAIN SCOPE (VLAN 08): Everything inside this room belongs strictly to Server OS Hardening, Hardware Root of Trust, Identity/Access Control, Encryption Standards, and Physical Data Center Security.

Hardware Root of Trust & Boot Integrity

  • TPM 2.0 (Trusted Platform Module): Dedicated hardware cryptoprocessor on the motherboard storing BitLocker/LUKS volume keys, platform PCR integrity measurements, and device certificates.
  • UEFI Secure Boot: Verifies cryptographic digital signatures of bootloaders, OS kernels, and option ROM drivers against trusted OEM keys before execution—blocking bootkits/rootkits.
  • Measured Boot: Records cryptographic hashes of every boot component into TPM registers so remote attestation servers can verify system integrity.
  • HSM (Hardware Security Module): Tamper-resistant physical appliance/PCIe card dedicated to generating, storing, and accelerating PKI root keys and TLS cryptographic operations.
  • SED (Self-Encrypting Drive): Hardware-level AES-256 disk encryption built directly into the drive controller with zero host CPU overhead.

OS Hardening & Mandatory Access Control

  • CIS Benchmarks & DISA STIGs: Industry-standard security configuration baselines defining hardened registry settings, password policies, and service restrictions.
  • Attack Surface Reduction: Disable unused services/daemons, remove unnecessary packages, close unused ports, disable default guest/admin accounts, and deploy minimal/Core server installs (no GUI).
  • SELinux & AppArmor (Linux MAC): Mandatory Access Control frameworks confining processes to strict security contexts/profiles even if a service is compromised as root.
  • Host-Based Firewall & HIDS/EDR: Restricting inbound/outbound traffic per server (Windows Defender Firewall, ufw/nftables) alongside file integrity monitoring (FIM) and EDR agents.

Identity, AAA & Privilege Governance

  • RBAC (Role-Based Access Control): Assigns permissions to security roles/groups rather than individual user accounts, enforcing the Principle of Least Privilege.
  • PAM (Privileged Access Management): Just-in-Time (JIT) elevation, password vaulting, credential rotation, and session recording for root/Domain Admin accounts.
  • Kerberos Authentication: Ticket-based mutual authentication protocol (TCP/UDP 88) relying on synchronized time (within 5 minutes) and a Key Distribution Center (KDC).
  • RADIUS vs. TACACS+: RADIUS (UDP 1812/1813) encrypts only the password and combines AuthN/AuthZ; TACACS+ (TCP 49) encrypts the entire payload and separates AuthN, AuthZ, and Accounting (preferred for network/admin device control).

Encryption & Physical Server Controls

  • Data at Rest: Full-disk/volume encryption using BitLocker (Windows), LUKS/dm-crypt (Linux), or SAN/NAS controller-level AES-256 encryption.
  • Data in Transit: Enforcing TLS 1.2 / 1.3, SSHv2, IPsec, LDAPS (636), and SMB 3.x Encryption while disabling SSLv3, TLS 1.0/1.1, Telnet, and FTP.
  • Physical Access Layers: Perimeter fencing → Mantrap / Access Control Vestibule → Biometric + Smartcard MFA → Locking perforated server rack cabinets → Chassis intrusion switches.
  • CCTV & Visitor Escort Logs: Continuous video surveillance covering all rack aisles and mandatory sign-in/escort logs for third-party technicians.
