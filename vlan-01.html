Storage Area Network (SAN)

Block-level storage fabrics, Fibre Channel, FCoE, iSCSI, NVMe-oF, WWN/IQN addressing, and MPIO.

DOMAIN SCOPE (VLAN 01): Everything inside this room belongs strictly to Block-Level Storage Area Networks (SAN). To the server OS, SAN storage presents as an unformatted raw local block device (LUN) that the server formats with its own file system (NTFS, VMFS, ext4, XFS).

Fibre Channel Fabric Architecture

  • HBA (Host Bus Adapter): Dedicated expansion card in the server that offloads Fibre Channel framing from the host CPU.
  • WWNN (World Wide Node Name): 64-bit unique identifier assigned to the entire HBA card or storage array controller.
  • WWPN (World Wide Port Name): 64-bit unique identifier assigned to each individual physical port on an HBA or FC switch (functions like a MAC address).
  • Fabric Topologies: Point-to-Point (FC-P2P), Arbitrated Loop (FC-AL, legacy), and Switched Fabric (FC-SW, modern standard using FC switches).
  • FLOGI / PLOGI: Fabric Login (HBA registers WWPN with the FC switch Name Server) and Port Login (session setup between initiator and target).

iSCSI Initiator & Target Mechanics

  • iSCSI Initiator: The client server requesting block storage (software initiator in OS or hardware iSCSI HBA).
  • iSCSI Target: The SAN storage array/server presenting LUNs over TCP/IP on port 3260.
  • IQN Format: iqn.yyyy-mm.naming-authority:unique-name (e.g., iqn.2026-01.com.corp:esxi-host01).
  • EUI Format: Extended Unique Identifier (eui. followed by 16 hex characters).
  • iSNS (Internet Storage Name Service): Automated discovery service that lets iSCSI initiators locate targets on large IP networks.
  • Jumbo Frames: Setting MTU 9000 end-to-end (initiator NIC, switch ports, target NIC) reduces TCP/IP overhead for block transfers.

SAN Security & Access Controls

  • Zoning (FC Switch Level): Isolates which initiator WWPNs can see and talk to which storage target WWPNs on the FC switch.
  • Soft Zoning vs. Hard Zoning: Soft zoning filters via the Name Server database (WWPN-based); Hard zoning enforces isolation physically by switch port/ASIC.
  • LUN Masking (Storage Array Level): Binds specific LUNs to authorized initiator WWPNs or IQNs so unauthorized hosts cannot mount the volume.
  • CHAP / Mutual CHAP (iSCSI): Challenge-Handshake Authentication Protocol authenticating the iSCSI initiator (one-way) or both initiator and target (mutual).
  • Dedicated Storage VLAN / Air-Gap: Isolating iSCSI traffic onto a dedicated non-routed storage VLAN prevents packet sniffing and congestion.

Multipathing & Block Workloads

  • MPIO (Multipath I/O): Uses dual HBAs/NICs, dual switches, and dual storage controllers to provide failover redundancy and load balancing across block paths.
  • ALUA (Asymmetric Logical Unit Access): Allows the host to identify active/optimized vs. active/non-optimized controller paths on active-passive SAN arrays.
  • Primary SAN Workloads: High-IOPS transactional databases (SQL, Oracle), clustered hypervisor datastores (VMware VMFS, Hyper-V CSV), and boot-from-SAN blades.
  • Boot from SAN: Server boots its OS directly from a remote SAN LUN via HBA BIOS/UEFI, allowing diskless servers to be swapped rapidly.
