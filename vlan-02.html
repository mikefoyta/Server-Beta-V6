Network Attached Storage (NAS)

File-level network storage appliances, SMB/CIFS, NFS, AFP, internal CoW file systems, and ACL permissions.

DOMAIN SCOPE (VLAN 02): Everything inside this room belongs strictly to File-Level Network Attached Storage (NAS). A NAS is a self-contained network appliance with its own OS, CPU, and internal file system that serves shared folders over standard IP networks.

NAS Architecture & Internal File Systems

  • Appliance Architecture: Dedicated storage head (CPU + RAM + NICs) running an embedded storage OS (TrueNAS, Synology DSM, QNAP QTS, NetApp ONTAP).
  • File-Level Abstraction: Clients request files by directory path and filename; the NAS appliance manages underlying disk blocks, metadata, and file locking.
  • ZFS (Zettabyte File System): Copy-on-Write (CoW) file system combining volume management, end-to-end data checksums (prevents silent bit rot), snapshots, and RAID-Z.
  • Btrfs / XFS / ext4 / NTFS: Common internal NAS file systems supporting ACLs, quotas, and journaling.
  • Write Caching (SLOG / ZIL): Dedicated fast NVMe/SSD cache used by NAS appliances to accelerate synchronous file writes.

Authentication, Permissions & Quotas

  • Directory Integration: Joins Active Directory (AD) or LDAP domains so users authenticate with centralized domain credentials.
  • Share Permissions vs. NTFS/ACL Permissions: Access is governed by the most restrictive combination of network share-level permissions and underlying file-system ACLs.
  • NFS Export Controls (/etc/exports): Restricts access by client IP/subnet, read-only (ro) vs. read-write (rw), and root_squash (maps remote root to unprivileged nobody).
  • User & Directory Quotas: Hard and soft storage limits enforced per user or per shared folder to prevent one department from filling the NAS.
  • File Locking (Oplocks / Leases): Prevents two users from overwriting the same document simultaneously over SMB/NFS.

NAS Networking & Throughput

  • Standard Ethernet Connectivity: Connects directly to standard Layer 2/Layer 3 Ethernet access/distribution switches via RJ45 (1GbE/10GbE) or SFP+/SFP28 NICs.
  • Routable Layer 3 Traffic: Because SMB and NFS run over TCP/IP, clients can reach a NAS across subnets, VLANs, and site-to-site VPNs.
  • LACP Link Aggregation (802.3ad): Bonds multiple physical Ethernet ports on the NAS to increase aggregate multi-client bandwidth and survive NIC/port failure.
  • SMB Multichannel: Automatically detects multiple NIC paths between Windows clients and a NAS to aggregate throughput without requiring switch-side LACP.

Primary NAS Workloads & Features

  • User Home Directories & Departmental Shares: Centralized document repositories, roaming profiles, and collaborative file servers.
  • Media & Archive Repositories: Video editing assets, ISO libraries, software installation repositories, and unstructured log archives.
  • Backup Target Destination: Receives backup jobs over SMB/NFS from backup servers and agents.
  • Copy-on-Write Snapshots: Instantaneous, space-efficient point-in-time file snapshots allowing self-service "Previous Versions" file recovery.
