DAS (Direct Attached Storage)

  • Drives attach locally to the server via SATA, USB, SCSI, or SAS—zero network connection between server and storage.
  • Still qualifies as DAS even with multiple drives and hardware RAID.
  • Simple and well-understood, but harder to scale or share across hosts than NAS/SAN.

NAS (Network Attached Storage — Table 4.1)

  • Pros: Accessed over standard TCP/IP Ethernet LAN/WAN; inexpensive; GUI-managed; supports multiple RAID levels & built-in backup software; easy Ethernet troubleshooting.
  • Cons: Higher latency & lower reliability than SAN; competes with regular LAN traffic (Ethernet congestion/packet drops); less effective for frequent OS rollback snapshots than SAN.

SAN (Storage Area Network — Table 4.2)

  • Pros: Dedicated high-speed private network separate from the LAN via storage switches; highly scalable; online maintenance without server downtime; long Fibre Channel runs; strong physical isolation.
  • Cons: Expensive; requires specialized admin skills; cannot leverage legacy investments; fewer vendors.
SK0-006 Exam Trigger A multi-disk external JBOD or RAID enclosure cabled directly to one server's SAS HBA without a network switch in between is DAS, not a SAN. Meanwhile, frequent VM/OS state rollback snapshots favor SAN over NAS.
Characteristic File-Level Access (NAS) Block-Level Access (SAN)
Data Presentation Stores and presents data as complete files and folders (file system owned by NAS). Presents raw storage blocks (LUNs); each block volume acts like an independent local hard drive formatted by the server OS.
Performance & Reliability Subject to file-protocol and TCP/IP LAN overhead. Higher performance and higher reliability over dedicated storage paths.
External OS Bootup Not supported for standard OS boot volumes. Supported—connected diskless blade/rack servers can boot their OS externally from a SAN LUN.
Best-Fit Workload Inexpensive, easy-to-manage bulk shared file storage. High-IOPS databases, virtualization datastores, OS boot-from-SAN.
SK0-006 Exam Trigger Whenever a scenario requires diskless servers to perform external bootup over storage infrastructure or demands raw block volumes treated as local disks, the architecture must be a Block-Level SAN.

NFS (Network File System)

  • Client/server file-sharing protocol primarily used in Unix / Linux environments (current standard: NFSv4).
  • Operates over TCP port 2049.
  • Secure NFS (SNFS) provides confidentiality using Data Encryption Standard (DES) per Sybex reference.

CIFS / SMB (Server Message Block)

  • Application-layer protocol used primarily in Windows networks for shared file and resource access.
  • CIFS (Common Internet File System) is a specific dialect of SMB (modern version: SMB 3.1.1 introduced with Windows 10 / Server 2016).
  • Operates directly over TCP port 445.
SK0-006 Exam Trigger Memorize the exact firewall port pair: NFS = TCP 2049 (Linux/Unix), SMB/CIFS = TCP 445 (Windows). Also remember that CIFS is a dialect of SMB, not a competing hardware bus.

Classic Fibre Channel (FC)

  • Dedicated high-speed optical storage network using specialized Fiber Switches (Fig. 4.14) and server Fiber HBAs.
  • Each Fiber HBA is addressed by a unique World Wide Name (WWN), which—like an Ethernet MAC address—includes an IEEE-assigned Organizational Unique Identifier (OUI).
  • Enables long-distance remote SAN connectivity and strict physical isolation from LAN traffic.

iSCSI (Internet SCSI — Table 4.4)

  • Encapsulates SCSI block commands inside standard TCP/IP packets over Ethernet (TCP port 3260).
  • Pros: Uses familiar Ethernet hardware, eliminates parallel SCSI cable distance limits, inexpensive in small deployments.
  • Cons: Software initiator CPU overhead can hurt performance; susceptible to IP network congestion; at large scale can cost as much as Fibre Channel.

FCoE (Fibre Channel over Ethernet)

  • Encapsulates native Fibre Channel frames directly inside Layer 2 Ethernet frames to converge LAN and SAN cabling onto 10GbE+ NICs (CNAs).
  • CRITICAL RULE: Unlike iSCSI, FCoE does NOT use IP or TCP at all—it operates strictly at Layer 2 and cannot be routed across IP subnets.
SK0-006 Exam Trigger Compare Figure 4.15 carefully: iSCSI carries Ethernet | IP | TCP | iSCSI | Data (Layer 3/4 routable). FCoE carries Ethernet | FCoE | FC | FC Payload (Layer 2 only—zero IP header!). Meanwhile, Fibre Channel HBAs are identified by WWNs, never IP addresses.

USB-to-SCSI Adapter (Figure 4.10)

  • Bridges legacy parallel SCSI peripherals (such as older tape drives or diagnostic arrays) to a modern server's USB-A port using an MD50-M (50-pin micro-D) SCSI connector.
  • Modern USB 3.0 storage enclosures leverage USB Attached SCSI (UAS) for command queuing and higher throughput.

Secure Digital (SD) & CompactFlash (Figure 4.11)

  • SD Capacity Tiers (Sybex p. 160): Standard SD (listed up to 512 GB in text / 2 GB legacy base), SDHC (High Capacity: up to 32 GB), and SDXC (Extra Capacity: up to 2 TB).
  • Three Physical SD Sizes: Standard SD, miniSD, and microSD (often used in servers for internal hypervisor boot or iDRAC/iLO vFlash service cards).
  • CompactFlash (CF): Larger legacy solid-state card format read via multi-card USB readers.
SK0-006 Exam Trigger Know the two key SD capacity thresholds: SDHC tops out at 32 GB, while SDXC scales up to 2 TB.

Why Documentation Fails

Poor record keeping combined with frequent IT staff turnover leaves teams unable to verify exact hardware counts, physical rack/room locations, or active warranty/license coverage during outages and audits.

Mandatory Storage & Hardware Records

  • Unique hardware identifiers: Serial numbers, asset tags, NIC MAC addresses, and Fiber HBA WWNs.
  • Physical topology & cabling maps: Rack elevation, PDU circuits, switch port mappings, and SAN zoning.
  • Lifecycle & compliance metadata: Purchase date, warranty expiration, firmware baselines, and disposal/sanitization certificates.
SK0-006 Exam Trigger When a scenario describes a newly hired administrator unable to locate undocumented servers, identify switch-to-SAN cabling, or prove hardware ownership during an audit, the root cause is a failure in Asset Management & Documentation.

Ethernet Header (iSCSI Outer Frame)

Wraps the IP packet for local hop transmission across standard Ethernet switches. Unlike FCoE, standard Ethernet switches do not require specialized lossless Fibre Channel extensions just to forward iSCSI frames.

CompTIA Exam Note Standard Jumbo Frames (MTU 9000) are frequently enabled on iSCSI Ethernet interfaces to reduce packet-fragmentation overhead during large block transfers.
