01 · DAS vs NAS vs SAN

Core memory anchor: DAS is a direct cable to local disk. NAS travels over LAN via TCP/IP for shared files. SAN (“SUN”) delivers block storage over a dedicated fabric, commonly Fibre Channel, or over IP using iSCSI. Raw LUNs are your “LUNar Space”.
ArchitectureAccess levelTransportHow OS sees it
DASBlock-levelSATA, SAS, NVMe, USB, ThunderboltLocal physical drive; low latency, simplest setup; not natively shared by independent servers.
NASFile-levelEthernet / TCP-IP; SMB/CIFS (Windows), NFS (Linux)Mapped network folder or mount point (\\server\share). NAS owns filesystem and file locks.
SANBlock-levelFibre Channel, iSCSI over IP, FCoERaw LUN appears as a disk to host OS; host formats it (NTFS, VMFS, XFS). Ideal for databases and hypervisors.
🖥️ DASServer → local drive
🗂️ NASClient → LAN → shared files
🛰️ SANHost → storage fabric → raw LUN

Exam discriminator: NAS shares files. SAN presents blocks that the host formats.

02 · Inside the SAN

Initiator

The host (ESXi, Windows or Linux) that requests block reads/writes.

Target

The storage controller or array that serves the blocks.

LUN

A logical slice of pooled physical disks presented as a block device.

MPIO

Combines redundant HBA/NIC, switch and controller paths into one logical disk for failover and load balancing.

04 · 42U rack assembly PBQ

Visual rack schematic. Read from U1 at the bottom to U42 at the top. Slot bands are teaching ranges, not a literal equipment-by-equipment installation schedule.

U35–U42 · ToR switches / patch panelsLight network gear
U29–U34 · Remaining rack spaceAllocate to actual design
U20–U25 · Pull-out KVMEye/chest-level ergonomic placement
U7–U28 · Storage & computeHeavy arrays lower; lighter servers above
U1–U6 · UPS / battery packsHeaviest equipment at base

Rear side rails: vertical zero-U PDUs · Front: cold aisle intake · Rear: hot aisle exhaust

Weight: place heavy UPS units and battery packs at the bottom to lower centre of gravity.

Cooling: align front-to-back airflow and use blanking panels in unused slots.

Cabling: put lightweight ToR switches and patch panels near the top; vertical PDUs occupy 0U.

PBQ nuance: U20–U25 overlaps the U7–U28 compute band. Reserve the selected KVM position rather than occupying it with another server.

05 · DNS troubleshooting & exact fixes

Match the symptom to its likely cause, then reveal the command. These are the four scenarios from your source.

1. One host uses old IP after migration; other hosts correct

Root cause: Stale local resolver cache

Check / fix A: Windows: ipconfig /flushdns

Check / fix B: Linux: sudo resolvectl flush-caches

2. Can ping IPs but cannot resolve internal names or join AD

Root cause: Wrong DNS server or missing AD SRV records

Check / fix A: ipconfig /all; Resolve-DnsName _ldap._tcp.dc._msdcs.corp.local -Type SRV

Check / fix B: cat /etc/resolv.conf

3. Forward lookup works; reverse lookup fails

Root cause: Missing/outdated PTR in reverse zone

Check / fix A: nslookup 10.1.1.5

Check / fix B: dig -x 10.1.1.5; create/update PTR

4. All clients get stale IP; secondary disagrees

Root cause: Stale A/AAAA/CNAME or failed AXFR due to SOA serial

Check / fix A: Update record on primary DNS

Check / fix B: Increment SOA serial to trigger replication
