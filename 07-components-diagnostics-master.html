4. Security Chips, Blade Components & AI Accelerators Specialized Silicon

  • TPM 2.0 (Trusted Platform Module): Motherboard crypto chip sealing BitLocker/LUKS keys and UEFI Secure Boot PCR hashes. Replacing a motherboard changes the TPM → triggers BitLocker 48-digit recovery key prompt.
  • Chassis Intrusion Switch: Physical plunger micro-switch under top cover that trips when opened (even powered off), logging a tamper alert in BMC SEL until cleared.
  • Blade Chassis Mezzanine Cards: Expansion NIC/HBA cards inside a compute blade route through the midplane to matching rear I/O switch/pass-through bays—both must match protocol (e.g., Fibre Channel).
  • AI GPU Form Factors:
    • PCIe CEM Cards (e.g., L4/H100 PCIe): 75W slot-powered (L4) or auxiliary 12VHPWR cabled (300–350W).
    • SXM / OAM Modules: High-TDP (700W–1000W+) baseboard modules wired directly into NVSwitch / UALink meshes.
